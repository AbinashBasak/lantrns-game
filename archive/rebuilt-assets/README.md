# Rebuilt assets

These files were reconstructed locally from recovered original source images or reviewed source recipes. They are not claimed to be the exact original sandbox-download bytes. Original generated source PNGs are preserved in `../shared-chat/images/`.

Seven animation packs each contain transparent frame PNGs, a horizontal sheet, a preview GIF, a contact sheet, and a source manifest. Runtime frames and Godot SpriteFrames are in `../../assets/characters/tavi/`.

The TAVI-012 source sheet depicts a complete eight-pose jump. Its full sequence is preserved here as `jump_start`; gameplay selects the separate rising/falling animations based on physics. TAVI-017 was not successfully delivered in the source chat.
