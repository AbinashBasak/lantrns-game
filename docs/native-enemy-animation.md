# Native enemy animation integration

The actual runtime scenes `scenes/enemies/thornling.tscn` and `scenes/enemies/hollow_sentinel.tscn` now contain editable AnimationPlayer clips, an active AnimationTree and native CPUParticles2D impact bursts. These are the existing prologue/Chapter 1 enemies, not replacements for the Chapter 3 species.

Open either scene in Godot, select **AnimationTree**, then open **States** in the bottom AnimationTree panel. Its graph connects every available art family. **Speed** scales the selected clip to the existing combat duration; scripts request states/speed and never play or manually step AnimatedSprite2D. The AnimationPlayer contains discrete animation/frame property tracks using the existing SpriteFrames artwork.

Thornling's native `telegraph` clip holds the first attack pose during its existing warning. Editable Line2D nodes now render its anticipation/strike cues. On defeat, gameplay collision/group membership and the reward signal end immediately while its own AnimationTree plays the existing defeat art before removal. The former temporary generated-animation actor is no longer constructed. Native impact particles honor reduced effects.

Hollow Sentinel's `dormant` clip holds its first idle pose. Wake, movement, windup, swipe, slam, transition and defeat preserve existing combat tempos and retained defeat pose. Its hazard visuals are now scene-authored too: `NativeVFX` contains Line2D/Polygon2D attack warnings, charge strip/instruction, a 260 px safe-ground zone, 34 fixed arena roots, two eruption regions, and the rejuvenation ring, native light and CPU motes. `VFXAnimationPlayer` owns warning pulse, root-rise and revival timelines. The controller supplies locked attack anchors, facing and state visibility; it no longer constructs or draws warning geometry. Damage regions, health, the two-life rage sequence and reward timing remain unchanged. Reduced effects holds readable static danger cues and suppresses the extra revival particles/light. No missing Chapter 3 enemy actions have been invented.

Validation on Godot 4.7.2: `tests/native_enemy_animation_test.gd` passed every existing clip, frame progression owned by the tree, graph travel, warning hold, attack duration, death/reset and particle activation. Existing `tests/hollow_sentinel_rage_test.gd` passed all 12 encounter regression checks. Headless checks establish resource/state behavior, not visual lighting proof. Native editor import under sandbox emitted macOS/.NET permission warnings; focused runtime tests loaded these scenes successfully.

`tests/hollow_sentinel_native_vfx_test.gd` additionally validates source positions against the actual arena/safe gap, fixed berserk eruption targets, editable strike timeline progression, revival light/particles and full reset. It and all 12 existing rage checks pass after the hazard migration.
