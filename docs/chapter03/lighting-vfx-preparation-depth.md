# Supplied depth and bitmap: native material demonstration

The actual Chapter 3 source138 broken arch (`C3-PROP-008`) and source142 temple wall (`C3-TILE-012`) now have serialized editable `CanvasTexture` resources in `resources/chapter_03/lighting/`. Each resource uses the existing high-resolution diffuse export, a bump normal derived from its supplied grayscale depth panel, and its supplied bitmap as a restrained specular mask. This follows the user's instruction to use those supplied maps for real Godot light response.

The unchanged panels remain under `art/source/chapter_03/environment/guide_panels/`. Derived files are explicitly under `art/vfx/chapter_03/derived_normals/`. The depth/bitmap crops are not assumed to line up: the preparation script removes panel borders, fits each visible silhouette to the actual exported diffuse canvas, checks thresholded silhouette overlap and records every transform. Depth/bitmap overlap scores are 0.881/0.908 for the broken arch and 0.962/0.960 for the wall. These generated guide panels are tonal interpretations, so this verifies silhouette registration rather than guaranteeing exact internal feature registration. The wall provides the stronger matching pair.

The normals are **derived bump normals**, not authored normal maps and not direct grayscale relabeling. The script blurs the supplied grayscale height by 1.5 pixels, computes central gradients, normalizes `(-8dx, +8dy, 1)` to Godot's X+, Y+, Z+ convention, and encodes the result as RGB. A four-pixel diffuse alpha-edge exclusion flattens boundary normals to limit relief outside the actual prop. No geometry or background is inferred. The supplied bitmap drives low-intensity specular response; it is not presented as physically authored roughness.

Open `scenes/vfx/chapter_03/c3_depth_lighting_review.tscn`. An editable native AnimationPlayer moves two real PointLight2D nodes from left to right and back over four seconds. The lights use shared radial falloff, height100, energy1.45 and no shadow polygons; light response comes from CanvasTexture surface normals and the bitmap. No runtime script assembles this scene.
