# Asset provenance

The story and original generated artwork were supplied in the user's ChatGPT conversation: https://chatgpt.com/share/6ad136a4-4cc8-83ee-9742-05bc90e2a1dc . Original generation metadata and prompts are preserved with the archive. Reference boards and alternate/rejected attempts are stored as reference material. This setup does not claim that generated artwork is exclusive or release-ready.

Tavi's runtime frames are derivatives of those original sheets. Their source image hashes and crop rectangles are recorded in each animation manifest. The prologue now uses selected generated ENV-01, terrain, prop, Mote, Rootling and UI exports from the production archive, plus procedural FX/audio generated by the project tools. Rusk and the cart-tender supporting sprites were generated with the built-in image_gen tool; their unchanged source atlases, prompts, crop records and hashes are preserved in ENV-01 metadata and the runtime manifests. The project icon and older Forgotten Trail scenery remain code/vector prototype assets. No third-party stock art or search-result reference photos are included in gameplay.

Godot is MIT licensed. Include the appropriate Godot license and third-party notices when distributing an exported game; the editor's Help → About → Third-party Licenses provides the installed engine notices. No exported release is included in this initial setup.

The archive also includes 47 third-party reference images that appeared in the source chat. Their original source URLs are recorded in the embedded-reference manifest and image gallery. Their inclusion in the archive does not grant rights to use them in the game; none are used in gameplay.

Prologue runtime source/output records: [prologue-asset-integration.json](prologue-asset-integration.json). The pack contains no embedded third-party reference gallery or original production archive. Runtime integration is not an assertion of exclusive ownership or final audio/art release approval.

Chapter 1 integrates selected generated ENV-02 Forgotten Trail and ENV-03 root-temple artwork, Hollow Sentinel animation exports, OBJ-002 fragment/UI graphics, ENV-04 orchard-memory layers, and generated chapter audio/effects. Mechanical atlas isolation and alpha crops preserve the original sources. Source/output hashes are recorded in the chapter runtime manifests and [Chapter 1 integration record](chapter01-asset-integration.json). The earlier code/vector trail remains a separate regression scene; it is not the new chapter's environment. No third-party web artwork was imported for this chapter. Prepared but unused animation variants are distinguished from active runtime integrations; neither status implies final production approval.


Chapter1 jungle expansion reuses generated ENV-02/03 and TILE-001/002 exports, plus Sporeling EN-012/013/014 and Brambleguard EN-016/017/018 animation frames. The [expansion asset record](chapter01-expansion-assets.json) preserves source/output hashes. Reference games inform route structure only; no reference-game artwork was imported. Runtime use does not imply final production approval.

Chapter1 rewards additionally use four generated PROP-014 chest states with mechanical alpha cropping; [provenance](chapter01-rewards-assets.json). Existing UI-008 textures provide the player health frame. Boss rejuvenation reuses generated collapse/wake/transition frames; new root effects are code-rendered animation. No third-party images were introduced.
